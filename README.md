# QolJetim AI

**«Бір сабақ — әр балаға тең мүмкіндік»**

Инклюзивті білім беруге арналған веб-платформаның демо-прототипі. EdTech-хакатон, №3 кейс «Инклюзивті білім беру».

🔗 **Демо:** https://shermo67.github.io/qoljetim-ai/

## Не істейді

Мұғалімнің дайын ҚМЖ-сынан оқушының нәтижесіне дейінгі тұтас процесс:

**ҚМЖ (.docx) → ЕББҚ тапсырмасын табу → бейімдеу → мұғалім бекітеді → жалпы ҚМЖ-ға кіріктіру → оқушы кабинеті → орындау → нәтиже мұғалімге**

- ЕББҚ оқушысына бөлек жоспар жасалмайды: бейімделген тапсырма жалпы ҚМЖ-ның тиісті кезеңіне кіріктіріледі.
- Мұғалім диагноз емес, педагогикалық қолдауды таңдайды. Таңдауға болатын 7 қолдау түрі: қарапайым тіл, қадамдап орындау, әріпті үлкейту, мәтінді дыбыстау, көрнекі мысал, қосымша уақыт, қысқа нұсқаулық.
- Оқушы кабинетінде мыналар бар: А−/А+, дауыстап оқу (қазақ дауысы бар болса), жауапты бірден айтпайтын қадамдық көмек, көрнекі топтар, жауапты тексеру, прогресс.
- Бейімделген ҚМЖ-ны Word пішімінде жүктеуге болады: бастапқы құжат сақталады, тек ЕББҚ блогы қосылады.

> **Ашық айтамыз:** бейімдеу қазір **ережеге негізделген демо-механизм** арқылы жүреді, тілдік модель қолданылмайды. Демо-механизм бөлу тапсырмаларын (математика) қолдайды. Әр ұсынысты мұғалім тексеріп, бекітеді.

## Іске қосу

Ештеңе орнатудың қажеті жоқ, интернетсіз де жұмыс істейді:

1. `index.html` файлын жүктеп алыңыз.
2. **Microsoft Edge** немесе Chrome браузерінде ашыңыз.

Демо-тапсырмалардың (120 : 12, 240 : 24, 360 : 36) нұсқаулығы адамның дауысымен алдын ала жазылып, файлға кірістірілген, сондықтан ол интернетсіз ойнатылады (`src/audio/`). Жазбасы жоқ тапсырмалар үшін браузердің қазақ дауысы қолданылады, мысалы Microsoft Edge-тің Aigul/Daulet дауыстары (интернет қажет). Қазақ дауысы табылмаса, қосымша басқа тілдегі дауысты қолданбайды, оның орнына ескерту көрсетеді.

## Деректер

Барлық деректер (ҚМЖ, тапсырмалар, нәтижелер) тек браузердің `localStorage` жадында сақталады және ешқандай серверге жіберілмейді. Нақты балалардың деректерін енгізбеңіз. Диагноздарды жазбаңыз.

## Құрылымы

```
index.html                 # дайын қосымша (бір файл, тәуелділіксіз)
src/app.js                 # логика: DOCX оқу, бейімдеу, кабинеттер, Word экспорты
src/styles.css             # стильдер
src/audio/                 # тапсырмалардың жазылған дауысы (120_12.m4a ...)
src/tools/build.py         # src + samples + audio → index.html жинау
samples/KMZh_51_...docx    # мысал ҚМЖ (4-сынып, математика, №51 сабақ; мұғалімнің рұқсатымен)
```

Кодты өзгерткеннен кейін: `python3 src/tools/build.py`

DOCX файлы браузердің кірістірілген `DecompressionStream` құралы арқылы оқылады. Сыртқы кітапханалар қолданылмайды.

## Жоспарда

- Ата-аналар мен сүйемелдеу мамандарына арналған кабинеттер
- Интернетсіз жұмыс істейтін қазақша дыбыстау
